## Reproduce locally

Only Python's standard library is required:

```bash
python tools/author_catalogue.py
python tools/build.py
python tools/check_design.py
python -m unittest discover -s tests -v
python tools/build.py --check
python tools/verify_package.py
```

`author_catalogue.py` indexes the authored text, not external sources. An intentional source edit changes the generated catalogue/master and therefore the original package manifest. Hash mismatches after deliberate editing are expected; do not rewrite the original receipt to imply unchanged delivery.

The final ZIP is also extracted into a fresh temporary directory, checked for unsafe paths and CRC errors, verified against its manifest, regenerated, and retested by the packaging process. Those outcomes are recorded in the external delivery receipt rather than claimed as additional gameplay evidence.
