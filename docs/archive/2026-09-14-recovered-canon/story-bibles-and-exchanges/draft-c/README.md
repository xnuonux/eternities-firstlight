# Firstlight — The Living Canticle / Draft C

An expansion of the existing story and production bible, prepared for Dom on 2026-09-13.

## Contents

- **FIRSTLIGHT_LIVING_CANTICLE_DRAFT_C.md** — the approximately 9,900-word design expansion: original mythology, intersecting acts, grief and reunion, spirit-form recovery, Luna and the seven fictional counterparts, alternative beginnings, multiple characters, and realm aesthetics.
- **ASTRA_TO_CODEX_LIVING_CANTICLE_RELAY.md** — the shorter implementation handoff. Its milestones are proposed; it authorizes no automatic source migration or full-game rewrite.
- **BRANCH_INDEX.json** — an editorial index of proposed branches, their viewpoints, methods, outcomes, and later payoffs. This is not executable quest data, a balanced progression model, or an imported runtime module.
- **SOURCE_REVIEW.json** — source identities, reading scope, and explicit limits.
- **MANIFEST.json** — SHA-256 hashes for package files other than the manifest itself.

## What changed

The founder's new request replaces a blanket story prohibition on the first companion's death with one authored loss-and-return arc. It does not make ordinary pets disposable or impose a death on existing progressed saves. A complete playable reunion is part of the proposed feature, not a future paid or unfinished add-on.

The campaign now has intersecting personal and regional threads rather than only a sequence of destinations. Luna and the seven receive fictional dramatic roles grounded in selected Canon/Scheduler role definitions, with real systems and private history kept outside the game.

## What did not happen

No new game build, code test, branch merge, GitHub write, deployment, production-agent connection, Supabase access, private-memory import, or personal-save mutation occurred. The original 2023 novel was not reread or revised. The source concordance and prior game adaptation remain distinguishable from these new inventions.

New names are working proposals. The first saga's resolved victory does not claim to implement the eventual metaphysical ending of the entire world.
