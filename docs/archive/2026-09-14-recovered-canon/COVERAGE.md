The 26 top-level source ZIPs passed CRC checks. Recursive inspection covered 56 embedded ZIPs and 7,306 member entries for safe paths, font-binary extensions, and selected credential markers. No matches requiring removal were found. Git bundles were retained but not decoded for this archive scan. This is a narrow archival safeguard, not exhaustive security certification or a rerun of game/scientific tests.

Uploaded source and convenience files have local SHA-256 manifests. Verification receipts distinguish remote listing checks from files actually downloaded back and compared. No public sharing grants were made; no existing files were overwritten.
